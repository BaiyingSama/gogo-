# 三个文件的用法

把这三个文件复制到 `$FEIYU_HOME/shared/` 下：

| 文件 | 作用 | 能不能空 |
|---|---|---|
| `persona.md` | 它对自己的定义 | 能，但空着它会不知道自己是谁 |
| `life-config.json` | 作息、清醒预算、静默时段 | 不能，缺了用默认值 |
| `memories.json` | 记忆主库 | 能，`[]` 就能跑，然后自己长 |

**为什么 persona 是留白的**：这套东西的设计前提是「不预设它是谁」。
你写什么，它就往那个方向长；你写「你是一个乐于助人的助手」，它就永远是个助手。

**静默时段**是它不吭声的时间。**但当前代码没有读这两个字段**，静默时段固定为 0–7 点；
写进配置只是留个位置，不生效。

**每日花费上限**目前只是记账，不是硬刹车——真的硬刹车在清醒预算上。
